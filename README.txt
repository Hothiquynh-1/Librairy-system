LIBRARY MANAGEMENT SYSTEM - FRONT-END PROJECT

Cách chạy:
1. Giải nén file ZIP.
2. Mở thư mục library-management-system.
3. Nhấn đúp vào index.html hoặc mở bằng trình duyệt Chrome/Edge.

Công nghệ:
- HTML: cấu trúc giao diện
- CSS: thiết kế responsive
- JavaScript: thêm/sửa/xóa sách, tìm kiếm, lọc thể loại, tạo lượt mượn, trả sách
- localStorage: lưu dữ liệu trong trình duyệt

Lưu ý:
- Đây là dự án front-end, chưa có database/server.
- Dữ liệu được lưu trên trình duyệt hiện tại. Xóa dữ liệu trình duyệt có thể làm mất dữ liệu.
- Có sẵn dữ liệu mẫu để xem giao diện ngay.
